# Engine scope

The root [agent instructions](../AGENTS.md) also apply. This directory contains inherited Smogon calculation source, build output, tests, and license notices. Read [calc/README.md](README.md), the relevant mechanics source, and the [Emerald Kaizo baseline report](../docs/design/Emerald-Kaizo-Baseline-Report.md) before changing calculation behavior. Do not infer game correctness from reference parity.

- Keep a mechanics change narrowly tied to complete battle inputs and expected results in the issue. Preserve inherited attribution and licenses.
- Run the relevant `calc/` tests and the root Emerald Kaizo comparison sequence in [Developer Setup](../docs/Developer-Setup.md#validation-by-change). Report both results; do not silently refresh expected fixtures to make a mismatch pass.
- `calc/dist/` and bundles are generated by the inherited build. Edit source, then regenerate outputs only when the build or integration needs them; review any generated diff. The root baseline scripts read selected inherited files directly.
